# Agenda Inteligente - Aplicación Móvil (Taller Semana 9)

**Estudiante:** Mónica  
**Proyecto:** Agenda Inteligente Móvil  
**Framework:** Flutter (Dart)  

---

## 1. Justificación Técnica del Framework
Se seleccionó **Flutter** como framework multiplataforma debido a su rendimiento nativo mediante compilación directa ARM/x86, motor gráfico independiente, capacidad de renderizado fluido y su completa suite de herramientas de diagnóstico CLI (`flutter doctor`).

---

## 2. Versiones del Entorno de Desarrollo
- **Flutter SDK:** 3.x (Dart SDK integrado)
- **Editor:** Visual Studio Code
- **Destino de Ejecución:** Dispositivo Físico Android (`24044RN32L` via USB)
- **Backend Target:** API REST en Node.js / Express (Puerto 3000)

---
